# Ultrasonic Distance Monitoring Radar System

## Overview
An Arduino-based radar system that uses an HC-SR04 Ultrasonic Sensor and Servo Motor to detect objects, measure distance, and display real-time radar-style visualization.

## Features
- Real-time object detection
- Distance measurement
- Radar-style visualization
- 180° scanning using servo motor
- Low-cost and efficient design

## Technologies Used
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- Arduino IDE
- Processing IDE
- C Programming

## Duration
February 2026 – April 2026

## Applications
- Robotics
- Obstacle Detection
- Security Systems
- Industrial Automation
